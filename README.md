# Exercice 1 : Suivi des Livres dans une Bibliothèque
<img width="352" height="362" alt="image" src="https://github.com/user-attachments/assets/4b73e57c-48ca-4308-bef5-46184cc5557e" />



Dans cet exercice, j’ai créé une classe `Livre` contenant trois attributs : le titre, l’auteur et l’année de publication. J’ai également utilisé un attribut statique `nbLivres` pour compter le nombre total de livres créés. J’ai implémenté un constructeur pour initialiser les attributs et incrémenter le compteur à chaque création d’un objet. J’ai ajouté une méthode `afficher()` pour afficher les informations de chaque livre et une méthode statique `afficherTotal()` pour afficher le nombre total de livres. Dans la fonction `main()`, j’ai créé trois objets `Livre`, affiché leurs informations et vérifié le fonctionnement du compteur. Cet exercice m’a permis de comprendre l’utilisation des attributs statiques et des méthodes statiques en C++.


# Exercice 2 : Gestion des Étudiants et de l’Université

<img width="324" height="229" alt="image" src="https://github.com/user-attachments/assets/b05a0e55-340c-4a82-a7fb-2e49fe9dd8db" />


Dans cet exercice, j’ai créé deux classes : `Universite` et `Etudiant`. La classe `Universite` permet de stocker et d’afficher le nom de l’université. La classe `Etudiant` contient le nom, l’âge et un pointeur vers un objet `Universite`. J’ai utilisé un attribut statique `nbEtudiants` pour compter le nombre total d’étudiants créés, ainsi qu’une méthode statique `afficherTotal()` pour afficher ce nombre. Dans la fonction `main()`, j’ai créé une université et deux étudiants associés à celle-ci, puis j’ai affiché leurs informations et vérifié le compteur. Cet exercice m’a permis de pratiquer les attributs statiques, les méthodes statiques, les pointeurs d’objets et l’association entre classes.
